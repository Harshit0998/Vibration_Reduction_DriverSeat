# Vibration Reduction in a Driver's Seat

A mechanical engineering project on reducing the vibration a driver feels while sitting in a vehicle.

Long exposure to seat vibration causes discomfort and fatigue, and over time it is linked to back problems in people who drive for a living. The usual fix is a spring and damper under the seat, but a normal suspension has a limit: to isolate low-frequency vibration well, you need very soft springs, and very soft springs let the seat sag and bounce too much under the driver's weight.

This project looks at a negative stiffness mechanism as a way around that trade-off. The idea is to add an element that pushes in the same direction the seat is already moving, which cancels out part of the main spring's stiffness. The result behaves like a very soft spring for vibration purposes while still holding the driver's weight properly.

## What is in here

MATLAB code that models the seat suspension and simulates how it responds to vibration input, comparing a conventional suspension against one with the negative stiffness element added.
